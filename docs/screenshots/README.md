# Screenshots

This directory contains screenshots of the Project RawHorse application for use in documentation.

## Adding Screenshots

When adding screenshots:
1. Use descriptive filenames: `dashboard-overview.png`, `browse-entities-tab.png`, `pyramid-l3-drilldown.png`
2. Prefer PNG format for UI screenshots
3. Crop to the relevant area — avoid showing browser chrome or desktop
4. Keep file sizes reasonable (< 500KB each; compress with a tool like TinyPNG if needed)

## Current Screenshots

Screenshots from the README are currently hosted via GitHub user-attachment URLs. To improve reliability, key screenshots should be added here and referenced via relative paths:

```markdown
![Dashboard](docs/screenshots/dashboard-overview.png)
```
