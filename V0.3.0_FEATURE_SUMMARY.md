## 🎯 What's New

Version 0.3.0 brings **powerful new capabilities** for financial network analysis and data expansion:

### 1. **Enhanced Analysis Page** 🔍
The Analysis page now features **5 interactive visualization sections**:

- **Network Graph** - Entity relationships with 10 color-coded types
- **Weighted Money Flow Graph** - Financial flows with thickness = amount
- **Spending Timeline** - Year/quarter/month aggregations with Recharts
- **Financial Dashboard** - Top recipients, agency breakdown, distribution charts
- **Flow Tracer** - Discover multi-hop financial paths between entities

### 2. **Pattern Detection & Anomaly Detection** 🎲
Detect unusual patterns in financial data:

- **Spending Spikes** - Z-score analysis finds anomalously large transactions
- **Award Clustering** - Identify rapid funding events (3+ awards in 30 days)
- **Funding Gaps** - Detect interruptions >180 days
- **Periodic Patterns** - Find recurring/annual funding cycles

**20+ new API endpoints** for comprehensive financial analysis.

### 3. **Multi-Hop Flow Tracing** 🔗
Discover indirect financial connections:

- **Path Discovery** - Find all routes between any two entities (up to 10 hops)
- **Critical Intermediaries** - Identify entities controlling flow pathways
- **Circular Flows** - Detect money cycles
- **Interactive UI** - Click to expand paths, see amounts at each step

### 4. **Network Analysis** 📊
Understand network structure:

- **Centrality Metrics** - Degree & betweenness centrality (NetworkX)
- **Community Detection** - Louvain algorithm finds funding clusters
- **Weighted Rankings** - Financial power metrics

### 5. **Dataset Expansion Tools** 📁
Ready-to-execute scripts for adding entities:

- **Defense Contractors** - USASpending API → 50+ contractors
- **Academic Institutions** - NSF Awards API → 30+ universities
- **FFRDCs/UARCs** - 24 centers integrated (Caltech, MIT, etc.)
- **NGOs** - UAP research organizations (SCU, Galileo, UAPx, etc.)

### 6. **Data Quality Tools** ✅
Maintain high-quality data:

- **Review Queue** - Manual verification workflow
- **Duplicate Detection** - Fuzzy matching & identifier comparison
- **Entity Merging** - Consolidate duplicates

## 🚦 Getting Started

### 1. Install Dependencies

```bash
# Backend
cd backend
pip install networkx==3.2.1 scipy==1.11.4

# Frontend (already has recharts)
cd frontend
npm install
npm run build
```

### 2. Launch Application

```bash
# Windows
RUN.bat

# Mac/Linux
./RUN.sh
```

### 3. Explore Features

1. Navigate to **Analysis** page
2. Try the **Flow Tracer** - trace paths between entities
3. Check **Money Flow Graph** - see weighted financial connections
4. View **Spending Timeline** - track trends over time
5. Explore **Pattern Detection** via API endpoints

## 📝 Execution Guides

### Add Defense Contractors

```bash
cd data/scripts

# Step 1: Fetch from USASpending
python fetch_usaspending_multiagency.py \
  --keywords_file ../reference/keywords_expanded_contractors.txt \
  --agencies_json ../reference/agencies_contractor_expansion.json

# Step 2: Aggregate top recipients
python aggregate_top_recipients.py \
  --data_dir ../external/contractors_expansion \
  --output ../contractors/top_contractors.csv

# Step 3: Migrate to database
python migrate_contractors_to_entities.py \
  --contractors_csv ../contractors/top_contractors.csv
```

### Add Academic Institutions

```bash
# Step 1: Fetch from NSF
python fetch_nsf_awards.py \
  --keywords_file ../reference/keywords_academic_institutions.txt

# Step 2: Extract institutions
python extract_institutions_from_nsf.py \
  --data_dir ../external/nsf_awards \
  --output ../academic/nsf_institutions.csv

# Step 3: Migrate to database
python migrate_institutions_to_entities.py \
  --institutions_csv ../academic/nsf_institutions.csv
```

## 🔗 API Endpoints Preview

### Pattern Detection
```bash
# Detect spending spikes
GET /api/analysis/patterns/spikes?threshold=2.5

# Find award clustering
GET /api/analysis/patterns/clusters?window_days=30

# Comprehensive analysis
GET /api/analysis/patterns/comprehensive?entity=Lockheed%20Martin
```

### Flow Tracing
```bash
# Trace paths
GET /api/analysis/flow-trace?source=DARPA&target=Raytheon&max_hops=5

# Find intermediaries
GET /api/analysis/flow-trace/intermediaries?source=Pentagon&target=Boeing

# Detect cycles
GET /api/analysis/flow-trace/circular?entity=AARO
```

### Network Metrics
```bash
# Full network analysis
GET /api/analysis/network-metrics

# Entity centrality
GET /api/analysis/network-metrics/centrality/Lockheed%20Martin

# Community detection
GET /api/analysis/network-metrics/communities
```
